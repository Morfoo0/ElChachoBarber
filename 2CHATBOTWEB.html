Construcción y Despliegue de una Aplicación Web Inteligente en la Nube

En esta práctica de laboratorio transformarás tu agente inteligente en una Aplicación Web interactiva profesional. Aprenderás a construir interfaces conversacionales con Streamlit, gestionar estados en memoria (st.session_state), publicar tu código en GitHub de forma segura y desplegar gratis en Streamlit Community Cloud para construir tu portafolio profesional.

1

¿Qué es Streamlit y por qué lo utilizaremos?

Streamlit es un framework de código abierto que permite convertir scripts de Python en aplicaciones web interactivas y atractivas en cuestión de minutos, sin necesidad de escribir código HTML, CSS o JavaScript.

Ventajas clave para ingeniería:

  • Manejo nativo de UI de Chat: Componentes integrados como st.chat_message() y st.chat_input().
  • Persistencia de Estado (`st.session_state`): Mantiene la conexión con Gemini y el historial sin reiniciar la memoria entre mensajes.
  • Despliegue directo en la nube: Sincronización automática con GitHub para publicar sitios web con dominio HTTPS gratuito.
2

Instalación de Dependencias Locales en VS Code

Abre la terminal integrada de VS Code (Ctrl + ~) y ejecuta el siguiente comando para instalar Streamlit y el SDK unificado de Google GenAI:

Terminal de VS Code (PowerShell / CMD) 
python -m pip install --default-timeout=1000 streamlit google-genai
💡 Consejo de red: La bandera --default-timeout=1000 previene fallos de descarga si la conexión en la escuela o en casa experimenta latencia.
3

Gestión de Carpetas y Rutas de Archivos en VS Code

Un error común al ejecutar Streamlit es recibir el mensaje: Error: Invalid value: File does not exist: app.py. Esto ocurre cuando la terminal está ubicada en una carpeta diferente a la carpeta donde guardaste tu script.

Para asegurar una ejecución correcta, tienes dos opciones:

  • Opción A (Recomendada - Cambiar de carpeta en la terminal):
    Utiliza el comando cd para navegar hasta la carpeta exacta donde guardaste tu archivo app.py:
    Comando de Navegación 
    cd "C:\Ruta\A\Tu\Carpeta\De\Practicas"
  • Opción B (Ruta completa en el comando):
    Indica la ruta absoluta encerrada entre comillas al ejecutar el servidor de Streamlit:
    Comando con Ruta Absoluta 
    python -m streamlit run "C:\Ruta\A\Tu\Carpeta\app.py"
4

Creación del Código Fuente Principal (`app.py`)

Crea un archivo llamado app.py en tu carpeta de trabajo y pega el código optimizado. Este script incluye protección con try-except para tus claves y memoria persistente para el cliente de Gemini:

app.py (Código Completo y Actualizado) 
import streamlit as st
from google import genai
from google.genai import types

# ==============================================================================
# 1. CONFIGURACIÓN DE LA PÁGINA WEB
# ==============================================================================
st.set_page_config(
    page_title="Asistente AI - Sistemas Inteligentes",
    page_icon="🤖",
    layout="centered"
)

st.title("🤖 Asistente Virtual 'Astra'")
st.caption("UAdeO • Materia: Sistemas Inteligentes • Dra. Aiblis Susej Herrera Palafox")

# ==============================================================================
# 2. GESTIÓN SEGURA DE LA API KEY (LOCAL Y STREAMLIT CLOUD)
# ==============================================================================
try:
    # Intenta leer la clave desde los secretos de Streamlit Cloud
    api_key = st.secrets["GEMINI_API_KEY"]
except Exception:
    # ⚠️ REEMPLAZA ESTA CADENA POR TU CLAVE REAL DE GOOGLE AI STUDIO PARA PRUEBAS LOCALES
    api_key = "GEMINI_API_KEY"

# ==============================================================================
# 3. CONFIGURACIÓN DE PERSONALIDAD DEL BOT
# ==============================================================================
CONFIG_INSTRUCCIONES = types.GenerateContentConfig(
    system_instruction=(
        "Eres 'Astra', un asistente académico inteligente, formal y estructurado para la materia "
        "Sistemas Inteligentes de la UAdeO. Tu objetivo es explicar conceptos de Inteligencia Artificial, "
        "Agentes y Redes Neuronales de forma clara y accesible. Si te preguntan por entregas o fechas, "
        "indica amablemente que deben verificar las indicaciones de la Dra. Aiblis Susej Herrera Palafox."
    ),
    temperature=0.7
)

# ==============================================================================
# 4. INICIALIZACIÓN PERSISTENTE EN MEMORIA (PREVIENE ERRORES DE CONEXIÓN)
# ==============================================================================
# Se guarda tanto el cliente como el chat en st.session_state para mantenerlos vivos
if "client" not in st.session_state or st.session_state.get("current_api_key") != api_key:
    st.session_state.client = genai.Client(api_key=api_key)
    st.session_state.current_api_key = api_key
    st.session_state.chat_session = st.session_state.client.chats.create(
        model="gemini-3.8-flash",
        config=CONFIG_INSTRUCCIONES
    )

# Historial gráfico de mensajes
if "messages" not in st.session_state:
    st.session_state.messages = [
        {"role": "assistant", "content": "👋 ¡Hola! Soy Astra. ¿En qué tema de Sistemas Inteligentes te puedo ayudar hoy?"}
    ]

# ==============================================================================
# 5. BARRA LATERAL (OPCIONES DE REINICIO)
# ==============================================================================
with st.sidebar:
    st.header("⚙️ Opciones del Agente")
    st.markdown("Modelo backend: **Gemini 3.8 Flash**")
    if st.button("🧹 Limpiar Conversación"):
        st.session_state.chat_session = st.session_state.client.chats.create(
            model="gemini-3.8-flash",
            config=CONFIG_INSTRUCCIONES
        )
        st.session_state.messages = [
            {"role": "assistant", "content": "🧹 La sesión ha sido reiniciada. ¿Qué otra duda tienes?"}
        ]
        st.rerun()

# ==============================================================================
# 6. RENDERIZADO DEL HISTORIAL DE MENSAJES
# ==============================================================================
for message in st.session_state.messages:
    with st.chat_message(message["role"]):
        st.markdown(message["content"])

# ==============================================================================
# 7. ENTRADA DE TEXTO Y PROCESAMIENTO
# ==============================================================================
if user_input := st.chat_input("Escribe tu pregunta o duda aquí..."):
    # Renderizar el mensaje del usuario de inmediato
    st.session_state.messages.append({"role": "user", "content": user_input})
    with st.chat_message("user"):
        st.markdown(user_input)

    # Generar la respuesta llamando a la API de Gemini
    with st.chat_message("assistant"):
        with st.spinner("Pensando respuesta..."):
            try:
                response = st.session_state.chat_session.send_message(user_input)
                st.markdown(response.text)
                st.session_state.messages.append({"role": "assistant", "content": response.text})
            except Exception as e:
                st.error(f"❌ Error al consultar la API: {e}")

Ejecución de la Aplicación en Servidor Local

REGLA IMPORTANTE: Las aplicaciones de Streamlit NO se ejecutan presionando el botón de Play (▶) de VS Code ni usando el comando `python app.py`. Deben ejecutarse a través de su propio módulo.

Abre tu terminal en VS Code y escribe:

Comando Correcto de Ejecución 
python -m streamlit run app.py
⚠️ Si ves el error `'streamlit' no se reconoce...`:
Significa que la ruta de Streamlit no está en tus variables globales de Windows. Ejecuta el servidor usando la ruta completa de tu Python:
& C:\Users\TU_USUARIO\AppData\Local\Python\pythoncore-3.14-64\python.exe -m streamlit run app.py

Se abrirá automáticamente la ventana de tu navegador en http://localhost:8501. Envía varios mensajes seguidos para confirmar que responde de forma continua.

Archivos de Configuración para GitHub (`requirements.txt` y `.gitignore`)

Para preparar tu proyecto para la nube, crea los siguientes dos archivos en la misma carpeta que `app.py`:

1. `requirements.txt` (Define las librerías a instalar en el servidor de la nube):

requirements.txt 
streamlit
google-genai

2. `.gitignore` (Evita subir claves privadas o temporales a internet):

.gitignore 
.streamlit/secrets.toml
__pycache__/
*.pyc
7

Publicación en GitHub y Despliegue en Streamlit Cloud

  1. Ingresa a github.com y crea un repositorio público llamado asistente-gemini-streamlit.
  2. Sube tus 3 archivos (app.py, requirements.txt y .gitignore) desde el panel de Control de Código Fuente de VS Code (Ctrl + Shift + G) usando Publish to GitHub.
  3. Abre share.streamlit.io e inicia sesión con tu cuenta de GitHub.
  4. Haz clic en Create app, selecciona tu repositorio y la rama main.
  5. En la sección desplegable Advanced settings..., localiza la casilla de Secrets y agrega tu API Key así:
    Secrets de Streamlit Cloud 
    GEMINI_API_KEY = "TU_GEMINI_API_KEY_REAL_AQUI"
  6. Haz clic en Deploy!.
